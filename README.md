📚 Library Management System 🐍

💻 A simple and beginner-friendly Library Management System built using Python.

🌟 About The Project

The Library Management System is a console-based Python application designed to manage books in a library.

🎯 The project allows users to:

📖 View all available books

📤 Issue a book

📥 Return a book

➕ Add a new book

🚪 Exit the program

This project is perfect for beginners who want to practice basic Python programming concepts.

✨ Features

📚 Show Books

Displays all books currently available in the library.

Shows a message if no books are available.

📤 Issue Book

Allows users to issue an available book.

Removes the issued book from the available books list.

Displays an error message if the book is not available.

📥 Return Book

Allows users to return a book.

Adds the returned book back to the library.

Prevents duplicate books from being added.

➕ Add Book

Allows users to add new books.

Checks whether the book already exists.

Prevents duplicate book entries.

🚪 Exit

Allows the user to safely exit the program.

🚀 How To Run
1️⃣ Install Python

Make sure Python is installed on your computer.

Check the installed version using:

python --version

2️⃣ Save the Program

Save the Python code in a file named:

library_management.py

3️⃣ Run the Program

Open your terminal or command prompt and run:

python library_management.py
